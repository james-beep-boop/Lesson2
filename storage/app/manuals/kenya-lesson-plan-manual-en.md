# Kenya Lesson Plan Manual

This manual explains how to use Lesson2 to view, edit, compare, share, and administer lesson plans in Kenya.

## Viewing Lessons

- Browse lessons from the **Lessons** menu and click on a lesson to view it.
- The official version is highlighted with a green checkmark — it is the school's approved edition.

## Editing Lessons

- Click **Edit This Plan** to enter edit mode.
- Make your edits in the edit window.
- Pasting from Word or Google Docs? Use **Paste as Plain Text** (Ctrl+Shift+V / Cmd+Shift+V) to avoid formatting problems.
- Choose a version bump: **Patch** (small fix), **Minor** (new content), or **Major** (complete rewrite).
- Add an optional revision note, then click **Save Edits** to create the new version.

## Comparing Versions

- On the lesson page, use **Compare to Previous Version** or **Compare to Official Version** for instant diff shortcuts.
- Or choose any version from the Compare section in the left sidebar.
- Additions are highlighted in **green**, deletions in **pink**.
- Toggle between **Side-by-Side** and **Stacked** layouts using the button in compare mode.

## Official Versions

- The official version is the school's approved edition for a lesson.
- Only one version per lesson family can be official at a time.

## Favorites

- Click **Mark as Favorite** (★) on any version to save it to your personal list.
- You can only favorite one version per lesson family.
- A warning appears if your favorited version differs from the current official version.

## Messaging Other Users

- Use **Message About This Lesson** to contact another user about a lesson.
- Messages to you appear in your **Inbox** (accessible from the user menu, top right).
- Click any message row to read it; you can reply from the message view.

## Translate to Swahili

- While viewing a lesson plan, click the **Translate to Swahili** button to translate that lesson.

## Ask AI

- When viewing a lesson plan, you can ask AI to suggest improvements, check for clarity, simplify the lesson plan, or anything at all.

## Print & Export

- **Print**: opens your browser's print dialog with a clean layout.
- **Save PDF**: saves the selected version as a PDF file.
- **Email PDF**: enter any email address to send the lesson plan as a PDF attachment.
- **Save .docx**: saves the selected version as a Word (.docx) file.
- **Email .docx**: enter any email address to send the lesson plan as a .docx attachment.

## Deletion Requests

- Click **Request Deletion** on a version to flag it for removal.
- A Site Administrator must approve the request before the version is deleted.
- The contributor and all site administrators are notified by inbox message when a request is submitted.

## User Types and Permissions

- **Teachers** can browse lessons, compare versions, favorite versions, message other users, translate to Swahili, print, and export.
- **Editors** can do all of that, edit lesson plans within their assigned subject and grade, and use the **Ask AI** function.
- **Subject Administrators** can do all editor actions for their subject-grades, mark a version official, request deletion, and promote teachers to be editors.
- **Site Administrators** can manage subjects, grades, users, subject-grade assignments, and deletion requests.

## Administration

- From the **Admin Panel** (top menu), manage subjects, grades, users, and pending deletion requests.
- Assign roles: set a Subject Administrator for each subject/grade, or add editors via the **Team** page.
- Approve or reject deletion requests from the Deletion Requests admin resource.
